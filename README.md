# 🌦️Get Live Weather Desktop Notifications
This project is a Python-based desktop application that provides live weather updates for any city using the OpenWeatherMap API.
## 🧠Project Overview
The program fetches real-time weather data — including temperature, humidity, pressure, and weather description — and displays it as a desktop notification at regular intervals.Built with Python libraries like requests (for API calls) and plyer (for notifications), this project demonstrates the use of API integration, automation, and real-time data retrieval in Python programming.
## ⚙️Features
* 🌤 Fetches live weather data from OpenWeatherMap API
* 🖥 Displays hourly weather notifications on desktop
* 🌡 Shows temperature (°C), pressure, humidity, and description
* 🧩 Easy to customize for any city
* 🔁 Runs automatically at fixed intervals
## 🛠 Tech Stack
* Language: Python
* Libraries: requests, plyer, time
* API: OpenWeatherMap
